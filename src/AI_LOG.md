## สรุปการใช้ AI

ใช้ AI เพื่ออธิบายแนวคิดและช่วยแก้ปัญหาการตั้งค่า IntelliJ ส่วนการออกแบบคลาสในข้อ 1-2 และโค้ด `Lab02.java` เขียนเอง

## รายการที่ใช้ AI

### 1. อธิบายแนวคิด instance variable / instance method / class variable / class method
- **ถามอะไร:** ขอให้อธิบายความหมายของ 4 คำนี้ และอธิบายโจทย์ lab แต่ละข้อ
- **AI ตอบอะไร:** อธิบายว่า instance เป็นของแต่ละ object ส่วน class (`static`) เป็นของคลาสและใช้ร่วมกัน พร้อมตัวอย่างการเรียกใช้ (`object.ชื่อ` กับ `ชื่อคลาส.ชื่อ`) และตัวอย่างคำตอบข้อ 1-2
- **ใช้ผลอย่างไร:** ใช้ทำความเข้าใจ แล้วออกแบบรายการ variables/methods ของ `AirPurifier` เอง
- **ตรวจสอบอย่างไร:** `<เช่น เทียบกับสไลด์ lec02 หน้า 19-20, 25>`

### 2. ตัวอย่างโค้ด `AirPurifier.java`
- **ถามอะไร:** ขอให้เขียนคลาส `AirPurifier` ให้ตรงกับ `Lab02.java` ของตัวเอง
- **AI ตอบอะไร:** ให้โค้ดตัวอย่าง มี constructor, `turnOn`, `turnOff`, `setFanSpeed`, `setPM25`, `getModelCount` และตัวแปรแบบ `static final`
- **ใช้ผลอย่างไร:** ใช้เป็นโครงตั้งต้น แล้วปรับแก้เอง `<ระบุสิ่งที่แก้ เช่น เพิ่มข้อความ "Invalid speed" เมื่อตั้งลมเกินช่วง>`
- **ตรวจสอบอย่างไร:** รันกับ `Lab02` แล้วตรวจผลลัพธ์ทุกบรรทัดตรงกับที่คาดไว้ (exit code 0, Count: 2)

### 3. แก้ error การคอมไพล์ใน IntelliJ
- **ปัญหา:** `Cannot compile module 'lab02' configured for JVM target 27` ขณะที่ JDK เป็น 25
- **AI ตอบอะไร:** แนะนำให้ปรับ Language level และ Bytecode version เป็น 25
- **ผลลัพธ์:** แก้แล้วรันได้

## ส่วนที่เขียนเอง
- การออกแบบ instance/class variables และ methods (ข้อ 1)
- แผนการทำงานของ method (ข้อ 2)
- `Lab02.java` และกรณีทดสอบ (ข้อ 4)
